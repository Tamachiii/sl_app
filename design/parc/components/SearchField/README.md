# SearchField

Le champ de recherche d'une liste, sous le grand titre.

## Ce que fournit l'appelant

- Un `<label>` qui contient le champ, avec le libellé en `sr-only` (« Rechercher un athlète »).
- Le champ `pk-field` en `type="search"`, l'icône de loupe à gauche (`ink-2`) et un padding gauche de 42 px.
- Le texte d'exemple reprend le libellé, en `ink-3`.

## À éviter

- Un champ sans contour : `line-control` le rend visible sur `ground` comme sur `surface`.
